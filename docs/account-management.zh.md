# 账号与模型管理

[English](./account-management.md) · [文档目录](./README.zh.md)

在 **设置 → 订阅 → 对应服务商 → 管理** 中配置账号与服务商偏好。保存前的修改只属于本地草稿；取消不会写入磁盘。

## 配置含义

- **订阅显示名 / 模型显示名**：可在管理面板中自定义订阅名称（用于底部额度栏与订阅标题）以及单个模型的显示名称；留空可恢复默认。显示名仅用于界面展示，不作为路由或绑定 key。
- **别名**：可选标签，例如“个人”“工作”。独立模型条目显示别名，内部绑定使用稳定账号 key；改别名不会改变绑定。
- **参与 LLM 账号池（加入自动 Pool）**：允许这个账号参与普通对话模型入口的自动调度。默认开启。
- **账号池模型白名单（Pool 模型列表）**：限制该账号允许参与 Pool 的模型。“允许全部模型（包含以后新增的模型）”（未设置白名单）会自动跟随将来发现的新模型；显式选择则仅限所选列表；清空选择表示不允许任何模型参与。
- **独立模型入口**：为账号增加单独的模型选择条目。默认关闭，开启后直接绑定该账号，不随 Pool 切换。
- **提示缓存有效期（仅 Claude）**：在 Claude 的管理面板中可将对话缓存 TTL 覆盖为 `5 分钟`、`1 小时` 或 `跟随配置`。两种时长的缓存读取价格相同，1 小时缓存写入按基础输入价的 2 倍计费（5 分钟为 1.25 倍）；保存后从下一轮对话立即生效。
- **Google Antigravity 默认禁用**：由于上游风控与接口限制，Antigravity 默认关闭，需在 **设置 → 订阅 → Google Antigravity** 中确认风险提示后手动启用。禁用期间本地已保存的账号仍会保留，但不会发起请求；当前即使手动启用也仅限查看账号用量，无法正常使用模型。

Antigravity 的账号池白名单按模型分组管理，推理档位由模型选择器单独控制。旧版保存的 `-low`、`-medium`、`-high`、`-xhigh` 条目，只有在该账号的当前目录已用对应分组替代具体条目时才按分组匹配；仍存在的手动具体模型和未知 ID 保持原样，`-tiered` 不作猜测映射。读取不会改写配置，编辑器会显示对应分组，取消勾选并保存后不会被旧条目重新启用。该兼容处理不保留旧条目的推理档位限制，也不会修改默认推理档位。

## 工作与个人账号示例

| 账号 | 别名 | 加入自动 Pool | 独立模型入口 |
|---|---|---|---|
| 个人账号 | 个人 | 开启 | 可选 |
| 工作账号 | 工作 | 关闭 | 开启 |

普通模型条目只使用允许参与 Pool 的账号。选择带“工作”别名的独立模型条目后，该模型调用只使用工作账号；账号被删除、独立入口被关闭、凭据失效或额度不足时，不会静默改用个人账号。

## 范围与限制

这些配置约束插件的 **LLM 对话模型路由**，不是整个会话的隐私隔离开关。图片生成、视频生成和 X 搜索等工具仍使用各自的账号策略；指定其他模型的子代理也不因此自动绑定账号。需要严格的工作/个人数据隔离时，不能只依赖此设置。

服务商级 **编辑模型列表** 继续管理模型显示、上下文和工具偏好；账号管理不重置这些设置。默认账号星标与 Pool 参与开关是两个不同配置。
